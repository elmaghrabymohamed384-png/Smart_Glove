Component Roles & Usage

ATmega32
Serves as the main control unit that runs your C firmware, reads signals from all sensors, processes hand gestures, drives the LCD display, and transmits trigger commands via UART.

MPU6050 Sensor
Measures 3-axis acceleration and angular velocity over the I2C interface to track hand tilt, movement, and orientation.

Hall Sensor
Detects changes in magnetic fields to capture discrete finger flexes or proximity movements, outputting signals directly to the microcontroller.

LCD with I2C PCF8574 Adapter
Displays real-time text, gesture translations, or system status updates using only two I2C pins (SDA and SCL) on the ATmega32.

Touch Sensors
using as pull_down buttons.

USB-to-TTL Converter HW-474
Bridges the UART serial output from the ATmega32 (TXD pin 15) directly to your laptop's USB port, enabling Python to catch trigger signals and play audio files on the laptop speaker.
